Program Explanation (Human-Friendly)

This program is basically a simple hotel management system. It helps the
hotel staff calculate room charges and store guest details in an
organized way.

1. Choosing a Room

The program first asks the user to pick a room type (1–4).
Each number represents a different room with its own price per night.
Once the user selects a room, the program sets the room price
automatically.

2. Calculating the Bill

The user then enters how many days the guest will stay.
The program calculates: - The total room cost (without GST) - GST at
20% - The final amount to be paid (room cost + GST)

This makes it easy for the staff to give guests an accurate bill.

3. Entering Guest Details

After the bill part, the program starts collecting guest information.
It asks for: - Name
- Nationality
- Phone number
- Address
- Check-in and check-out time
- Room number

If the guest is Indian, the program asks for their Aadhaar number.
If not, it simply notes that a passport is needed.

All this information is stored in a dictionary called “Record,” where
each room number holds the details of the guest staying in that room.

4. Storing Multiple Guests

The program allows entering details for multiple guests.
After each entry, the user can choose whether they want to add another
guest or stop.

5. Final Output

At the end, the program prints the complete record of all guests.
This helps in keeping everything organized and easy to access.

Overall, this program simplifies hotel check‑in, billing, and
record‑keeping.
